# Code of Conduct

The short version: be a good shipmate.

## Rules of the deck

1. **Claim what you can show.** zeuge is a witness tool; the community
   around it works the same way. If you are guessing, say so.
2. **No harassment, no slurs, no dogpiling.** Critique work, not people.
3. **No secrets in the repo.** No tokens, credentials, or personal data
   about anyone.
4. **MIT, honestly.** The license is short and permissive — do not present
   the tool as audited, certified, or compliance-ready. It is not.
5. **Disputes go to the maintainer.** The project owner's call is final.

## Enforcement

Open an issue describing the behavior, or use GitHub's private reporting.
The maintainer reads everything and answers in the open where possible.

Deliberately short. Deck rules of a small ship; if the ship grows, the
rules grow with it.
